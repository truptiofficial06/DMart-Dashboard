# DMart-Dashboard
1.Project Overview
The dashbord provides a comprehensive analysis of sales performance, customer behavior, and product trends. It helps in understanding how different factors like category, location, and discounts impact overall business performance.

2.🎯 Key Features
📈 Total Order Value KPI to track overall revenue
🛍️ Category-wise Sales Analysis
🌍 City-wise Insights using map visualization
👥 Customer Age Group Analysis
📊 Order Trends Over Time
🔎 Interactive Filters (City, Product, Ship Mode)

3.🧠 Insights Gained
Identified top-performing product categories
Observed how discounts influence total sales
Analyzed customer distribution across age groups
Compared performance across different cities

4.🛠️ Tools & Technologies
Microsoft Power BI
Data Visualization
Data Cleaning & Transformatio

5.🚀 Conclusion
This project demonstrates how data visualization can turn complex datasets into simple, actionable insights. It reflects my ability to analyze data and present it in a clear, interactive, and visually appealing way.
